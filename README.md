# 🎚️ Slider me CSS

Slider (range input) i stiluar me CSS dhe me vlerë live nga JavaScript. Lëviz kursorin dhe vlera përditësohet menjëherë.

## 🚀 Si ta hapësh

Hap `demo/index.html` në browser dhe lëviz slider-at — numri pranë secilit përditësohet live.
